# Calculadora La Solución

Aplicación web con IA desarrollada en Streamlit para apoyar a estudiantes y emprendedores con matemáticas aplicadas.

## Funcionalidades:
- Derivadas, integrales, límites y evaluación de funciones
- Explicaciones paso a paso
- Gráficas interactivas
- Exportación de resultados
- Interfaz moderna con fondo oscuro
- Versión consola incluida para uso local
- Compatible con despliegue en Streamlit Cloud y creación de .exe

## Cómo desplegar en Streamlit Cloud:
1. Sube este repositorio a GitHub.
2. En [https://share.streamlit.io](https://share.streamlit.io):
   - Repository: usuario/repositorio
   - Branch: main
   - File path: `calculadora_la_solucion_streamlit_fondo_OK.py`
3. ¡Listo!
