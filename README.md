# Calculadora La Solución (Versión Mínima)

App web con IA en Streamlit para resolver derivadas, integrales, límites y funciones con pasos explicativos.

## Características:
- Diseño minimalista: solo texto, sin íconos ni imágenes
- Fondo oscuro, letras grandes y limpias
- Ideal para presentaciones, enseñanza o uso profesional

## Despliegue en Streamlit:
1. Sube este repositorio a GitHub.
2. En [https://share.streamlit.io](https://share.streamlit.io):
   - Repository: usuario/repositorio
   - Branch: main
   - File path: calculadora_la_solucion_minima_sin_franja.py
